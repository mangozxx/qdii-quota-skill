# QDII 申购额度查询 Skill

用一句话问出：**按基金公告的规定，哪些 QDII 基金现在能买、每天最多能买多少。**

示例："日本 QDII 今天能买多少？""纳指基金哪个限额最高？""摩根日本精选代销和直销分别限购多少？"

## 能做什么

- **额度榜单**：按地区（美股、日本、东南亚、印度、欧洲……）或主题（纳指、标普、日经、恒生科技、黄金、原油……）列出可以申购的基金，按单日限额从高到低排列。
- **单只基金明细**：查看一只基金各份额（A/C/D…）在代销、直销渠道的额度，附公告原文链接；主流代销平台的显示与公告不一致或暂不销售时，会在表下补充说明。
- **完整表**：连同暂停申购、休市的基金一起列出。
- **美元份额**：可单独查询美元份额的额度，与人民币份额分开排列。

> 这里的"额度"指**单个基金账户每天累计最多能申购多少钱**，不是基金公司的外汇额度。本 Skill 只提供信息查询，不推荐基金，也不下单。

## 数据从哪来

- **基金公告**：基金公司发布的公告原文，系统自动解析其中的限额、暂停、恢复和休市信息。
- **基金名单与业绩比较基准**：来自金融数据服务，每天更新一次。

默认按**代销渠道的公告口径**回答，也就是基金公告对所有代销机构的统一规定，不对应任何一家具体平台。

## 有什么不同

| | |
| --- | --- |
| **以公告为准** | 每个额度都来自基金公司的正式公告，并附公告原文链接 |
| **数据全** | 覆盖全部 QDII 基金：339 个产品、731 个份额 |
| **数据新** | 交易时段每 30 分钟更新；当天有变化的会标出"当日变更" |
| **懂时间** | 15:00 后或非交易日提问，会自动给出下一个受理日的额度；基金休市日、"明天起暂停"这类情况都会算进去 |
| **口径清楚** | 区分代销与直销；A/C 份额分开算、不能相加；人民币份额和美元份额分开显示 |
| **结果稳定** | 输出格式固定（一句结论 + 表格 + 暂停列表 + 说明），每次风格一致 |

## 安装

运行环境：Python 3.8 或以上，不需要安装其他依赖。

1. 下载本仓库（页面上的 Code → Download ZIP，或 `git clone`），把其中的 `qdii-quota` 文件夹放到所用 Agent 的 Skill 目录。
2. 在 `qdii-quota` 文件夹里运行 `scripts/qdii.py coverage` 自检（Python 命令按本机环境选择），能看到“数据覆盖与时点”就说明装好了。

不需要申请 Key，`config.ini` 里已经配好了公共访问。以上步骤也可以直接交给 Agent 完成。装好后重启 Agent，用自然语言提问即可。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 找不到 Python 命令 | 安装 Python 3.8 或以上，并确认命令行能调用 |
| 查询失败（HTTP 401） | 公共访问配置已更换或暂停，请下载本仓库最新的 `config.ini`；仍不行请提 Issue |
| 查询服务不可达 | 检查网络 |

## 看结果时注意

- 只有"单日上限"一栏是数字或"不限额"的份额，才是现在能买的。
- 公告口径是基金公司对代销渠道的统一规定，**具体销售平台可能设置更严的限额**。
- 数据最长约 30 分钟更新一次，**最终以实际下单页面为准**。

遇到额度和实际下单页面不一致、问题识别错了或者报错，请在本仓库提 Issue，附上**问题原文、截图和查询时间**。
