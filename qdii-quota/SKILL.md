# QDII 申购额度查询

“额度”指投资者在某个渠道**单个基金账户单日累计可提交的申购金额上限**，不是管理人的外汇 QDII 投资额度。数据来自 qdii-quota-api：产品公告解析 + 交易日历，交易时段每 30 分钟刷新。只做信息查询，不推荐产品、不下单。

> 本版本默认**在同一张表里同时给出代销和直销额度**：`rank` / `table` 不加 `--channel` 时，表里“代销”“直销”各占一列（代销 = 支付宝/天天基金等销售机构，直销 = 基金公司官方平台），榜单按两个渠道中较高的额度排序。代销口径是产品公告对代销渠道的统一规定，不对应任何一家具体平台，具体平台可能更严。

## 查询步骤

1. **解析意图**，映射成脚本参数（未提到的用默认值）：

   | 用户说法 | 参数 |
   | --- | --- |
   | 美股 / 美国股票 | `--region 美股 --asset equity` |
   | 美国债 / 美元债 | `--region 美国 --asset bond`（“美元债”泛指时不加 region，加 `--q 美元债` 也可） |
   | 日本、港股、东南亚、越南、印度、欧洲、中东、全球、中概 | `--region <原词>` |
   | 纳指、标普、日经、恒生科技、原油、黄金、半导体等指数/主题 | `--q <原词>`（匹配产品名、跟踪指数，或占业绩比较基准一半以上的成分指数）。“纳指”= 纳斯达克100/综合，“标普”= 标普500；用户说“纳斯达克系列”“纳斯达克生物科技”等时用 `--q 纳斯达克` 或原词 |
   | 前 20 / 前 5 | `--n 20`（默认 10） |
   | 只看有限额的、额度最高的有限额产品 | `--limited-only` |
   | 机构 | `--investor institution`（默认个人） |
   | 美元份额 | `--currency USD`（默认人民币；两种币种绝不混排） |
   | 只问直销 / 只问代销 | `--channel direct / agency`（默认不加，两个渠道都输出） |
   | 今天、现在、今日可投（默认） | 不加 `--as-of`：脚本按“现在下单哪天受理”取数，已过 15:00 或今天非交易日会自动改查下一交易日 |
   | 明天、某个具体日期 | `--as-of YYYY-MM-DD` |
   | 某只产品（代码或名称） | `fund <份额代码>`；只有名称时先 `table --q <名称关键词>` 找代码 |
   | “全部”“完整表”“包括暂停的” | `table` 而不是 `rank` |

2. **执行**（在本 Skill 目录）：
   ```bash
   python3 scripts/qdii.py rank  --region 日本
   python3 scripts/qdii.py table --q 纳指
   python3 scripts/qdii.py fund  007280
   python3 scripts/qdii.py coverage        # 用户问数据时点、覆盖范围时
   ```
   Python 命令因系统而异：macOS / Linux 用 `python3`；Windows 上 `python3` 不可用时依次改用 `python`、`py -3`。先用 `--help` 确认能运行，不要因命令名报错就判定服务不可用。
   配置 `QDII_API_BASE`、`QDII_API_KEY`：环境变量优先，否则读本目录下的 `config.env`（模板见 `config.env.example`）。需要 Python 3.8+，只用标准库。

3. **呈现**：**原样输出脚本的 Markdown**，不改动、不删减、不重排（标题、时点行、结论句、表格、暂停列表、“注”和链接都保留）。脚本已经给出结论句、表格之外的暂停/休市列表和统一的“注”，所以：
   - 不要在前后另写说明段落、风险提示或复述表格内容；
   - 如确有表中没有的必要信息（如用户问的产品不在榜单里），最多在脚本输出后加**一句**；
   - 一次提问只执行一条查询命令，除非用户的问题本身需要多条（如同时问两个地区）。

## 判定边界（必须遵守）

- 只有“单日上限”（或“代销”“直销”列）是数值或“不限额”的份额才在该渠道可买；额度对应时点行写明的那一天（可能是下一交易日）。暂停、休市、该渠道不销售、未知的不能说可买；“休市（恢复后 X）”里的 X 只是恢复开放后的额度。
- “✓ 已核实”= 产品公告与该渠道公开页面一致；“公告口径”= 只有产品公告；“⚠ 参考值”= 公告与渠道显示不一致或仅有渠道显示，表中已取较严值（脚本的“注”已说明，不必另写）。
- “代销（支付宝/天天基金等销售机构）”是产品公告对所有代销机构的统一规定，不代表任何一家具体平台；具体平台可能更严。单只产品明细表下的“补充”一行是与主流代销平台页面的核对结果，原样保留。
- A/C 等份额额度分别计算，不能相加；美元与人民币分开回答。
- “可买 N 只（M 个份额）”：N 按产品计数（同一产品的 A/C/I 份额算一只），M 是其中可买的份额个数；榜单和完整表口径相同。
- 15:00 截止和非交易日由脚本处理并写在时点行里，不要再自行查第二个日期。用户明确要“今天（已截止）”的额度时才加 `--as-of <今天>`。
- 脚本报错（未配置、401、服务不可达、视图尚未生成）时如实告知，不要凭记忆或网页搜索给出额度。
- 榜单第 N 名并列的产品已全部列出，展示数可能多于 N，不要截断。
